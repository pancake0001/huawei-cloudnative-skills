# CLI Dependencies

Install and configure `hcloud` for Huawei Cloud resource queries. For Kubernetes resource queries, use the `huawei-cloud-kubectl-cce-installer` skill to install and operate `kubectl` with the `kubectl cce` plugin.

The runtime must not print credentials. Pass temporary credentials only through `--cli-access-key`, `--cli-secret-key`, and `--cli-security-token` when required.
